## [0.1.0] - 2025-12-02

### Added

- Initial release of Filament Server Indicator plugin
- Display copyright text with `:year` placeholder support
- Display application version in footer
- Display server name from load balancer cookie
- Configurable cookie name for server identification
- Regex pattern support to strip server name prefixes
- Toggle visibility for copyright, version, and server name
- Optional request logging with server info
- Multi-tenant support with custom tenant resolver
- Publishable configuration file
- Publishable Blade views for customization
- Environment variable support for all settings
